# Technical Documentation Page 📖

Информационная страница технической документации с удобной навигацией по разделам кода. Проект выполнен для демонстрации навыков организации контента и работы со сложными макетами.

## 🚀 Демонстрация
[Посмотреть проект в действии](https://github.io)

## 🛠 Технологический стек
* **HTML5** — структурирование технического текста, списков, таблиц и блоков кода (`<code>`, `<pre>`).
* **CSS3** — реализация макета со стационарным боковым меню навигации, прокрутка контента и кастомизация шрифтов.

## 💡 Реализованный функционал
* **Двухколоночный макет:** Удобное боковое меню (Sidebar) для быстрого переключения между главами и основная область для чтения.
* **Адаптивность (Mobile-First):** На мобильных экранах боковое меню автоматически перестраивается в верхнюю панель для экономии места.
* **Стилизация кода:** Специальное форматирование для фрагментов программного кода, делающее его легко читаемым.

## 🔧 Как запустить проект локально
1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com
   ```
2. Откройте файл `index.html` в вашем браузере.
